### 2. [ProxyPool Web Manager（代理池管理工具）](https://github.com/maker-pro/proxypool-web-manager)

**Python · FastAPI · SQLite · Docker**

一个用于聚合和管理代理订阅的轻量级 Web 管理工具。

-   管理订阅来源，解析多种节点格式
-   对节点进行去重，并检测 TCP 连通性和延迟
-   生成 Clash 订阅以及 YAML / JSON API
-   支持本地运行和 Docker 部署

### 3. [Windows 批量视频下载工具](https://github.com/maker-pro/batch-video-downloader-windows)

**Python · Tkinter · Playwright · 异步 I/O**

一个用于 Windows 的桌面工具，可批量处理视频页面地址并下载支持的媒体流。

-   批量输入页面 URL，并根据页面标题生成文件名
-   从页面标记和浏览器网络活动中提取媒体链接
-   支持常见的 `m3u8`、`mp4` 和 `webm` 下载流程
-   支持并发下载，以及 HTTP / SOCKS5 代理配置
-   支持打包为 Windows 桌面程序

*仅用于下载用户有权访问和保存的媒体内容。*

### 4. [wx_book --- 微信阅读小程序](https://github.com/maker-pro/wx_book)

**微信小程序 · JavaScript · Lin UI**

一个以阅读为核心的微信小程序，包含以下功能：

-   热门书籍和书籍分类
-   书籍搜索与阅读页面
-   个人书架和加入书架
-   阅读字体大小和背景设置

### 5. [New Year Couplet Generator（新年对联生成项目）](https://github.com/maker-pro/new-year-couplet)

**PHP · Python · Redis**

一个对联生成项目，也用于实践 PHP 与 Python 之间的组件集成。

-   探索如何将 PHP Web 应用中的用户输入传递给 Python 进程
-   使用 Redis 作为组件之间的数据中转
-   记录实际集成和部署过程中的问题排查经验

### 6. [wx-tree --- 微信小程序练习项目](https://github.com/maker-pro/wx-tree)

**微信小程序 · JavaScript**

`rpx` 布局。
